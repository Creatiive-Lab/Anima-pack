# Assinatura Miguel · Advanced JSON Demo

Versão local avançada da assinatura Miguel / Creative ZONE.

## Destaques

- 16 camadas independentes.
- Tracks múltiplos por camada.
- Efeitos JSON-driven: glow, echo, shine.
- FX procedurais em canvas: embers, orbit sparks, energy arcs, flares e pulse rings.
- Parallax suave com inércia.
- Controle de velocidade, pausa, glow e FX.

## Arquivos

- `index.html`
- `styles.css`
- `player.js`
- `animation.json`
- `assets/atlas.webp`

## Observação

Este pacote foi preparado localmente para substituir a demo básica. Se desejar publicar, basta copiar a pasta para `animations/miguel-signature/` no repositório `Anima-pack`.
